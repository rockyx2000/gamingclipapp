# 0011 タグの付与は投稿者、削除は写った本人だけ

## 背景
自分の動画の視聴画面で、投稿者がタグを消せるのは不自然、との指摘があった。

## 決定
- タグを付ける・位置を直すのは投稿者（投稿時と編集画面）。
- 視聴画面でタグを外せるのは、タグを付けられた本人だけ（`ClipTags` の `user.id === tagged.id`）。
- 編集画面の保存は、タグが変わったときだけ `PUT /tags` を呼ぶ。

## 結果
- 投稿者は編集画面でタグを付け直せるが、視聴画面では本人のものしか外せない。
- 編集画面と削除（`PATCH` / `PUT thumbnail` / `DELETE /api/clips/:id`）は、投稿者だけが使える（無ければ 404、他人なら 403）。
