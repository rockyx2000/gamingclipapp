# 0010 タグは映像上の相対位置で持つ

## 背景
最初は「写っているユーザーを選ぶ」方式だったが、Instagram のように位置を指定して付けたい、との要望があった。

## 決定
`clip_tags(clip_id, user_id, x, y, created_at)` に、映像の範囲を 0〜1 に正規化した x, y を持つ。web は contain で収めた映像の矩形（`containRect` / `useContentRect`）に合わせて札を重ねる。付け方は、映像をクリックして位置を決め、ユーザーを選ぶ。札はドラッグで動かせる（ドラッグの直後に出るクリックは `suppressClick` で無視する）。

## 結果
- 画面サイズが変わっても、同じ場所に札が出る。
- 1 クリップに付けられる数に上限（`MAX_CLIP_TAGS`）がある。
- `PUT /api/clips/:id/tags` は `tags` が配列でないと 400 を返す（空の本文で全タグが消える事故を避ける）。
